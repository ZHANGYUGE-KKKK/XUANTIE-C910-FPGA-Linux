# C910_LEARN

`C910_LEARN` 分支用于学习和梳理玄铁 C910 / OpenC910 的 RTL 源码，帮助理解 CPU 的整体架构、各子模块功能、接口关系及指令运行流程，为后续 FPGA 开发提供参考。

## 主要内容

- `gen_rtl/`：C910 RTL 源码。
- [C910项目整体架构](C910项目整体架构.md)：整体层级、模块互联与当前配置说明。
- [C910零基础术语与运行流程入门](C910零基础术语与运行流程入门.md)：基础术语与 CPU 运行流程介绍。
- `docs/submodules/`：25 份子模块分析文档。
- `Temp/`：源码扫描辅助脚本及结果。

建议先阅读入门文档和整体架构，再结合子模块文档查看对应 RTL 源码。
