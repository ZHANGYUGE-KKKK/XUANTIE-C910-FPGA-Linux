浮点运算单元（FPU）是专门执行IEEE 754标准浮点运算的硬件模块。玄铁C906和C910都包含完整的FPU，但微架构实现有显著差异。C906采用顺序双发射架构，FPU与整数流水线共享取指和译码阶段；C910采用乱序执行架构，FPU作为一个独立的执行单元挂接在保留站（Reservation Station）之后。

FPU拥有独立的32个浮点寄存器（f0~f31），每个寄存器宽度为64位，可以存放一个双精度浮点数或两个单精度浮点数。浮点指令通过专门的浮点操作码（OP-FP）译码，由FPU内部的调度逻辑决定送入哪个计算单元。

生活类比

整数运算就像用普通计算器做加减乘除，每次按键立即出结果；浮点运算则像用科学计算器处理三角函数，内部需要更多步骤，但能处理更复杂的数（比如3.14×10⁻⁵）。FPU就是芯片里的"科学计算器"。

浮点流水线的深度与延迟

FPU流水线的深度直接影响浮点指令的吞吐量。C906的FPU采用3~5级流水线，C910的FPU采用4~7级流水线，具体级数取决于运算类型。

运算类型C906延迟（周期）C910延迟（周期）是否流水化
FADD.S / FADD.D34是
FMUL.S / FMUL.D45是
FDIV.S8~128~12否（占用单元）
FDIV.D12~1612~16否（占用单元）
FSQRT.S10~1410~14否（占用单元）
FCVT.W.S（整数转换）22是

加法、乘法、乘加（FMA）指令是流水化的，意味着每个周期可以发射一条新指令，即使前一条还在执行中。除法与开方指令是非流水化的，执行期间会独占除法/开方单元，后续同类指令必须等待。

常见误区

  • 误区一：认为浮点指令延迟固定。FDIV.S的延迟取决于操作数的尾数差值，差值越大迭代次数越多，延迟在8~12周期之间浮动。
  • 误区二：混淆吞吐量与延迟。流水化后吞吐量可达每周期一条，但单条指令的延迟并未缩短。
  • 误区三：忽略除法单元的资源竞争。连续执行多条除法指令时，后续指令会被阻塞，影响整体性能。

舍入模式与精度控制

IEEE 754标准定义了四种舍入模式：就近舍入（默认）、向+∞舍入、向-∞舍入、向0舍入。玄铁FPU通过浮点控制状态寄存器（FCSR）的FROUND字段选择舍入模式。

实际开发中，大部分团队选择默认的就近舍入模式，除非有特殊数值稳定性要求。我在项目中曾遇到一个案例：某个数值滤波算法在C906上跑出的结果与x86参考实现有微小差异，排查后发现是x86默认使用x87的80位扩展精度，而RISC-V FPU严格遵循IEEE 754单/双精度，舍入时机不同导致。解决方案是显式设置舍入模式并统一测试用例的精度期望。

编者提示：浮点运算的精度问题在嵌入式场景中容易被忽略。C906和C910的FPU都支持非规格化数（subnormal），但处理非规格化数会引入额外延迟（可达数十周期）。如果应用对实时性要求极高且数值范围可控，可以通过FCSR的NVE位（非规格化数异常使能）将非规格化数视为0，大幅提升最差情况性能。但注意：这会损失接近0的极小数值精度，不适合科学计算类应用。

浮点异常与状态标志

FPU在执行过程中可能产生五种异常：无效操作（NV）、除零（DZ）、溢出（OF）、下溢（UF）、不精确（NX）。这些异常通过FCSR寄存器中的异常标志位记录，不触发软件中断，除非通过FCSR的异常使能位显式开启。

异常类型触发条件默认结果
无效操作（NV）0/0、∞-∞、sqrt(负数)NaN（非数）
除零（DZ）有限数/0±∞
溢出（OF）结果超出最大有限值±∞（就近舍入时）
下溢（UF）结果小于最小规格化数非规格化数或0
不精确（NX）结果无法精确表示舍入后的近似值

如果你在调试中看到计算结果出现NaN（Not a Number），大概率是触发了无效操作异常。排查思路：检查除数是否为零、开方操作数是否为负数、或参与运算的某个变量未被初始化（浮点寄存器初始值为NaN）。

玄铁FPU的特殊设计考量

C906和C910的FPU都支持RISC-V的D扩展（双精度浮点）和F扩展（单精度浮点）。两者都实现了融合乘加（FMA）指令，如FMADD、FMSUB，将乘法和加法合并为一条指令，中间结果不进行舍入，精度更高且延迟更低。

FMA指令的硬件实现是FPU中最复杂的部分。C910的FPU中，FMA单元采用三级流水设计：第一级做乘法，第二级做加法和对齐，第三级做规格化和舍入。这个设计在面积和延迟之间取得了平衡。

一个隐藏的坑：C906的FPU在连续执行FMA指令时，如果结果写回寄存器后立即被下一条指令读取，需要插入一个气泡周期（pipeline bubble）。编译器通常会通过指令调度避免这种情况，但在手写汇编时容易踩坑。解决办法是在FMA指令后插入一条不相关的浮点指令（如FMV.X.W）来填充延迟槽。

关键知识点
  • 玄铁FPU支持单精度（32位）和双精度（64位）浮点运算，寄存器宽度64位
  • FMA指令（融合乘加）是浮点性能的核心，C910的FMA单元延迟5周期
  • 除法/开方单元非流水化，连续使用会形成性能瓶颈
  • FCSR寄存器控制舍入模式、异常使能和状态标志

浮点指令与整数指令的交互

浮点指令与整数指令之间的数据传递通过FMV.X.W（浮点→整数）和FMV.W.X（整数→浮点）指令完成。这些指令将浮点寄存器的位模式原样复制到整数寄存器，不进行任何数值转换。真正的格式转换使用FCVT.W.S等指令。

交互过程中有一个容易忽略的细节：浮点指令写回浮点寄存器后，整数指令读取同一寄存器（通过FMV.X.W）时，需要确保FPU的写回操作已经完成。C906采用顺序发射，这个依赖由硬件自动处理；C910的乱序执行中，保留站会检测这种跨单元的数据依赖，并插入必要的等待周期。

数据搬运

  • FMV.X.W：浮点→整数
  • FMV.W.X：整数→浮点
  • 不改变数值，只复制位模式

格式转换

  • FCVT.W.S：浮点单→整数
  • FCVT.S.W：整数→浮点单
  • 进行数值舍入/截断

比较与分支

  • FLE.S / FLT.S：浮点比较
  • FEQ.S：浮点相等判断
  • 结果写入整数寄存器供分支使用

  1. 定义两个双精度浮点数 a = 3.14159, b = 2.71828
  2. 计算 c = a * b + a / b，使用FMA指令实现
  3. 将c转换为32位整数，观察舍入结果

本章小结

  • 玄铁FPU独立于整数ALU，拥有32个64位浮点寄存器，支持单精度和双精度运算
  • 加法、乘法、FMA指令是流水化的，除法与开方指令非流水化且延迟较高
  • FCSR寄存器控制舍入模式（四种）和异常处理（五种异常标志）
  • FMA指令将乘加合并，精度更高，是浮点性能优化的关键
  • 浮点与整数数据交互通过FMV指令完成，格式转换通过FCVT指令完成
